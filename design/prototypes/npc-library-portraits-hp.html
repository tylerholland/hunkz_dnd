Each row now leads with a portrait thumbnail and trails with an HP chip (omitted when no default HP is set). The picker's "⚙ Enemies Gallery" link replaces Story 24's inline new-entry form; creation now routes to the full advance editor (Surface C, below).

    Map Token — Number Badge
