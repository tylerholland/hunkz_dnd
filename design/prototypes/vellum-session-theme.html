Element Broken (dark assumption) Fixed (vellum-aware)
HP bar fill #3a8a4a — mid-green hardcoded; near-invisible on warm parchment (#f5f0e8). Low contrast ratio ~1.4:1. var(--pal-accent) = #7a5c30 warm brown. Contrast ~4.8:1 against parchment bg.
HP bar track rgba(0,0,0,0.08) — dark-theme near-transparent looks correct on dark bg, washed on light. var(--pal-gem-low) = rgba(140,110,70,0.18) — warm tinted groove visible on parchment.
Condition pills (inactive) background: rgba(0,0,0,0.3) — near-black chip, legible on dark, illegible on parchment. Text white rgba also disappears. background: transparent, border: 1px solid var(--pal-border-vis), color: var(--pal-text-muted).
Condition pills (active) background: rgba(0,0,0,0.5), light-blue text — black on parchment creates aggressive dark blobs. background: var(--pal-accent-dim), border: var(--pal-accent), color: var(--pal-text).
Concentration banner background: rgba(0,0,0,0.4) — black block on parchment looks like an error state. background: var(--pal-accent-dim), border-left: 3px solid var(--pal-accent), color: var(--pal-text).
Spell slot pips (filled) #c8e4d0 (very pale green) — designed for dark bg; disappears on parchment. Empty border also invisible. Filled: var(--pal-gem) = #4a3418 dark brown. Empty border: var(--pal-border-vis).
Death save pips Success: #c8e4d0 pale — nearly invisible. Failure: #e4b4b4 pale — also fades. Empty: rgba(200,200,200,0.35) invisible. Success filled: #5a8a40. Failure filled: #a04040. Empty: var(--pal-border-vis). All visible on parchment.
Dice result bubble background: rgba(20,30,40,0.85) dark navy + color: #ffffff — clashes with warm manuscript aesthetic; dark widget on light page feels foreign. Inverted: background: var(--pal-accent) (#7a5c30), color: var(--pal-bg) (#f5f0e8). On-theme ink-on-parchment inversion.
Session notes area background: rgba(0,0,0,0.25) dark wash — creates muddy grey pool on parchment. White-ish text unreadable. background: var(--pal-surface-solid) = #e8e0cc. border: var(--pal-border-vis). color: var(--pal-text-body).
Inspiration toggle (active) Glow: box-shadow: 0 0 8px rgba(106,143,168,0.5) — blue ocean glow looks wrong on parchment; toggle bg near-invisible. background: var(--pal-accent-dim), border: var(--pal-accent), knob var(--pal-accent-bright). No glow — manuscript aesthetic uses ink weight, not glow.
Exhaustion counter text color: #c8bfaf — a light warm-grey value designed for dark backgrounds; reads as ~30% contrast on parchment. color: var(--pal-text) = #2a2018 — near-black, full contrast on parchment.

Implementation note: all fixes use CSS custom properties already defined on the Vellum palette object. No new variables needed — only the consuming components need conditional class or variable selection when palette === "vellum". The pattern is: set --pal-* vars at the sheet root (as today), and move all hardcoded color values in session-mode components to var(--pal-*) references. Vellum's token set already provides correct values for each element.
