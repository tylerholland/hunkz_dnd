Legend — Design Decisions & Annotations
1
Token layer as sibling div — lives inside the same transform wrapper as the map image. All tokens inherit CSS transform and scale naturally with zoom. No per-token math during pan/zoom.
2
Held floater outside transform — position:fixed element following cursor via JS, lives outside the map panel's overflow:hidden. FLIP-style handoff on drop: floater animates to image-space position then token mounts in place.
3
Select-then-click placement — click tray chip → HELD state. Click map → drop with bounce. Clicking the chip again or pressing Escape cancels. Works equally on touch without long-press drag.
4
Hover-expand breathes open — portrait scales 36→48px (220ms overshoot cubic), HP card slides in (+80ms, 200ms ease-out), label translates down (+120ms, 200ms ease-out). Collapse is synchronised 160ms ease-in.
5
--token-scale-multiplier — CSS variable on the token layer root. Calibration slider writes directly to element style, no re-render needed. Token px = 36px × multiplier × mapZoom.
6
FALLEN state — opacity 0.4, filter grayscale(0.6), inset red shadow on ring. Bandit token on map shows this state. In DM view hover-card has "Remove from map" button. Player view shows critical tier glow line.
7
Tray chip stagger — nth-child transition-delay at 40ms increments. Chips animate opacity + scale when .chip-visible class is added after tray opens (240ms + stagger per brief §10).
8
NPC ring color — uses --border (neutral gray) per brief §4b. NPC fill colors are hash-tinted: Goblin A = teal (#2a5a4a), Goblin B = brown (#4a3a2a), Bandit = red (#5a2a2a). Three goblins would be visually distinct.
9
Brief §16 calibration scope — Architect Notes §1 defers calibration to Story 29b. This prototype includes the full calibration popover UI for design validation; it is marked as deferred in implementation scope.
10
Fractional coordinates — Tokens are positioned at percentage of map width/height (e.g. left:28%, top:25%). In production these would be stored as 0.0–1.0 fractions and converted to px via imageNaturalSize × fraction.
11
HP card flip — .flip-up class flips card above the token when token is in the bottom 25% of viewport. Computed via getBoundingClientRect() against the MapViewer container rect (not document).
12
Cancel paths — Three paths to cancel HELD state: tap source chip again, Escape key, or × Cancel pill (44px touch target at bottom-left of map). All paths call the same cancelHeld() function. Bug 3 adds a fourth: click the tray strip while holding a map token to return it.
