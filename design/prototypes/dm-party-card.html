Mobile Behavior · 320px

At 320px the name row and meta row may get crowded. ↗ Sheet and ⋯ both shrink to fit — Sheet truncates gracefully since it's just two characters + arrow, and ⋯ is fixed-width. Long character names (e.g. "Aragorn Strider") truncate via text-overflow: ellipsis on .char-name, preserving the ⋯ button at the right edge. The AC badge column remains at its intrinsic width (auto). No wrapping, no stacking — both breakpoints use the same two-row structure.

Header redesign rationale The old layout made the actions column (AC + ⋯ + Sheet) the height driver of the header — it was always taller than the identity block (name + meta = 2 rows), forcing a third row of dead space on the left side. The fix is structural: move ⋯ to share the name row and ↗ Sheet to share the meta row. Both use margin-left: auto to push to the right edge of the identity column without adding height. The AC badge becomes a standalone grid cell and remains visually prominent at top-right. Net savings: ~28px of header height, which gives that space back to the combat stats below. On mobile (320px) the same two-row structure holds — long names truncate with ellipsis, and both action elements (⋯ and Sheet) are fixed-width so they never wrap.

Coin display rules (multi-denomination mode) The collapsed view shows a single line: GP [≈ NNN.NN gp] [↓]. The ≈ prefix (rendered smaller, muted) signals "this is a GP-equivalent conversion." The expand chevron is a 20×20px ghost button — present but unobtrusive. Tapping it flips to [↑] and reveals the denomination row below the summary line; the summary line itself does not move. The denomination row shows five pills (cp/sp/ep/gp/pp) using metallic color tints matching the coin type, followed by a Give button at the end. The Give button only appears in the expanded state, keeping the collapsed view clean. Tapping [↑] collapses back.

Conversion rules: 1 PP = 10 GP · 1 GP = 1 GP · 1 EP = 0.5 GP · 1 SP = 0.1 GP · 1 CP = 0.01 GP. Display: round to 2 decimal places; if the total is a whole number show no decimals; if zero show 0 gp.

GP-only mode (coinMode: "gp"): No conversion needed. Display as GP [NNN gp] [Give] — no ≈ prefix, no expand toggle, Give always visible in the summary row.

Saves strip observations The strip occupies a single compact line (~24px tall including its top border). Passive Perception uses a 13px Cinzel value in the palette accent color — it reads as the headline figure on this row. The three save modifiers (WIS · CON · DEX) follow in 11px Cinzel with muted 9px IM Fell English labels. The middot separators are faint (45% opacity) so they don't compete with the values. The top border matches the slots strip style — the same 1px palette-tinted line used elsewhere in the card — so the strip slots into the card stack without introducing new visual language. For non-casters (Card A), the saves strip connects directly below the HP block; for casters (Card B), it sits below the slot pips. In both cases, the Tier 2 divider immediately follows, keeping the clear break between combat-relevant and administrative information.

Why this layout over a two-column approach: A two-column grid would align the Perc value over the triad of saves, but that reads like a table — it asks the DM to scan vertically. The horizontal run PERC 14 · WIS +1 · CON +2 · DEX +3 is read in one left-to-right pass, matching how the DM already scans the card. The slight size difference (13px vs. 11px) gives Passive Perception the visual weight it deserves as the most-queried value (it's checked against every enemy that attempts to hide) without requiring bold or color contrast changes.
Tier Hierarchy
Tier 1a Portrait · name · race/class/level · AC · HP display + stepper + inline ⚔/✦ buttons. Always visible. These decide life and death. The HP bar stretches to fill the full 400px card width at desktop — giving fill-fraction reads much more visual range than a cramped 340px card.
Tier 1b Active conditions · concentration · inspiration. Only rendered when non-empty — the row vanishes entirely in the minimal state, no empty space.
Slots Spell slot pips (casters only). Read-only at a glance — filled pip = remaining, hollow = used. Disappears for non-casters.
Saves Passive Perception + WIS/CON/DEX save modifiers. Always visible, never expandable. Sits below the slots strip (or HP block for non-casters), above the Tier 2 divider. Single compact line: PERC value in accent color (13px), then three save pairs in muted type (11px), separated by faint middots.
Tier 2 XP strip (XP-mode only) · coin strip (always). Both are single compact lines that expand horizontally to fill card width at desktop. The XP bar and coin pill breathe without becoming full panels.
Tier 3 Notes strip: collapsed by default, expands in-place. DM note entry + player-shared notes. Count badge when notes exist.
Overflow ⋯ button: Add Condition, Set Temp HP, Drop Concentration, Short Rest, Long Rest. Passive ability/skill badges moved here or removed from DM card entirely.
