Long Rest — Hit Dice Recovery

Long Rest restores floor(level / 2) Hit Dice, capped at max. No extra UI needed — the existing Long Rest button handles this. Below shows the before/after of a Long Rest at different depletion levels.

RAW note — 5e PHB p.186: Long Rest restores spent Hit Dice equal to half your max (floor). So a 7th-level character recovers 3 Hit Dice — going from 1 → 4. A second Long Rest while at 4 would bring them to 7 (4 + 3 = 7, capped at max 7). The DM's Long Rest button already patches all characters via patchSession; it will now also write hitDiceCurrent = min(current + floor(level/2), level).
