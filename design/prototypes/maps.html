Section 1 — DM Dashboard: Map Viewer + Library Strip
DM Campaign Dashboard
The map viewer is a collapsible panel at the top of the party column. When expanded it shows the active map full-width with drag-to-pan and scroll/pinch-to-zoom. Small overlay controls (+/−/reset) sit in the bottom-right corner. The map library strip lives below the Enemies and Initiative columns — a horizontal scroll of thumbnails with a Set Active button per map, an Upload button, and a full-strip drag-drop zone.
Toggle above switches the DM viewer between an active map and the empty state. The library strip is always visible. Use the "Set Active" buttons in the strip to activate a map.

Section 2 — Upload Modal
Upload Modal
Triggered by clicking the Upload button in the library strip, or by dropping a file onto the strip. When a file is already known (drag-drop), the modal opens directly to the preview + name-entry state. When opened via button click, it shows the drop zone first.
The image preview is a full-width 180px strip showing the chosen image. A "Change file" overlay sits bottom-right. Map name is pre-filled from the filename (spaces, title case). Confirm is disabled until a file is present.
