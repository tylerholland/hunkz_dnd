Design Notes

1 Spacer ring is load-bearing — the 0 0 0 4px/6px surfaceSolid box-shadow layer on bleeding portraits creates a clean ring of card-background color that visually anchors each portrait to its own card. Without it, a portrait reads as floating between the two adjacent cards.
2 Accent stripe weld — in Options A and A+, a ::after pseudo-element on .cc-stripe widens the stripe at the portrait band so it merges visually with the portrait border. Portrait and spine read as one continuous accent element at the top-left corner.
3 AC badge relocation — Options A and A+ move AC below the ⋯ kebab in the actions column. This is required because at card width the header grid cannot fit portrait + name + meta + AC + kebab all in one row without compression. AC rank drops slightly but remains top-right.
4 16px gutter between cards — bleed values (-10px, -20px) are applied as margin-top on the portrait element only, not on the card. The card's physical top edge is unchanged. The portrait simply overflows it upward into the gutter, so inter-card layout is not disturbed.
5 State propagation — portrait borders and glow animations inherit card state (active-turn = gem pulse, 0HP = red death glow). The brief requires this so a bleeding portrait never visually decouples from its card during dramatic states like FALLEN or active combat.
6 Baseline desaturation — the "Current" column uses filter: saturate(0.78) brightness(0.92) to read as slightly dim relative to the proposed options, making comparison easier. This is a prototype-only annotation device; the actual current implementation is at full saturation.
7 Option A+ outer glow ring — the third box-shadow layer on the A+ portrait (0 0 0 8px rgba(accent, 0.25)) creates a soft accent halo beyond the spacer ring. This gives the medallion / campaign badge feel requested in the brief. Adjust alpha to taste.
8 Column top offset — Options A and A+ add margin-top: 14px / 24px to the first card in each column to give visual breathing room for the bleed above the first card. In a real scrolling column this space is naturally provided by the DM dashboard chrome above the card list.
