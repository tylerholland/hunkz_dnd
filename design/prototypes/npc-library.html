The "+ New library entry" button at the bottom of the list lets the DM add creatures without putting them in combat first.

    Legend
    ① ◇ From library toggle — IM Fell English 11px, uppercase, letter-spacing 0.18em, textMuted. The quietest possible affordance. Sits below the helper text, below the primary form fields, as a secondary path. Tab stop order is Name → HP → Count → + Add Enemy → this.
    ② × Close — Redundant close for when the picker is long and the toggle has scrolled off-screen. 32px touch target.
    ③ Row tap action — Name fills form input, abilities staged in form state, picker collapses (160ms ease-in), HP input receives focus after 80ms. Row briefly flashes npcPal.chipBg (120ms) on tap.
    ④ Ability preview — Crimson Text 11px, two-line clamp via -webkit-line-clamp: 2. Leading ◆ glyph now 11px, opacity 1 (was 10px, 0.85). Line-height 1.65 (was 1.45). Bottom padding on row increased to 10px for breathing room.
    ⑤ Row delete × — Two-tap delete. First tap shows [Delete] [Cancel] inline (max-height 0→32px, 180ms ease-out). 6-second auto-dismiss if no action taken. Delete committed: row slides out (max-height→0, opacity→0, translateX(8px), 220ms ease-in). Not undoable.
    ⑥ No abilities saved — "( no abilities saved )" in Crimson Text italic 11px textMuted. Edge case: DM saved a card with empty abilities field. Still selectable — name fills form. Visually demoted so it's clear what they're getting.
    ⑦ Empty library state — Dashed border (border: 1px dashed npcPal.actionBorder) distinguishes "not yet filled" from "populated rows." Copy is instructive: tells DM exactly how to populate via the ⋯ menu.
    ⑧ + New library entry — IM Fell English 11px uppercase, letter-spacing 0.16em, npcPal.accent. Full-row touch target (min-height 44px, padding 10px 12px). Sits below the last template row with a 1px border-top separator. On hover: color → npcPal.bright. On tap: button fades out (opacity 0, 100ms), inline form expands below (max-height 0→240px, opacity 0→1, 200ms ease-out cubic).
    ⑨ Inline add form — Name input (Cinzel 13px, auto-focused) + Abilities textarea (Crimson Text 12px, min-height 80px, resize:vertical, maxLength 255, placeholder "Abilities…\n(spells, attacks, special abilities)"). Cancel (ghost, IM Fell English 10px uppercase, textMuted) collapses form (160ms ease-in) and restores button at 100ms. Empty name submit flashes border-color #c06060 (300ms, 2 iterations). Successful add: entry prepended MRU at top of list (220ms ease-out reveal), form collapses, button restored, focus returns to Name input.
    ⑪ ⋯ overflow button — IM Fell English 14px, textMuted. 32px square touch target. Sits between + Init and × in the header. Hover → npcPal.bright. Tap opens overflow popover anchored top-right.
    ⑫ Save to library (fresh) — Crimson Text 14px, npcPal.bright. ◆ glyph left. Padding 10px 14px. Full-row touch target. After tap: row shows ✓ Saved (220ms, npcPal.bright) then popover dismisses. Only success affirmation in the feature.
    ⑬ Remove enemy — Separated from save by 1px divider. color: #c06060. Acts identically to the card's existing × button. Included for hit-target redundancy and DMs who reach the menu first.
    ⑭ Conflict label — IM Fell English 10px uppercase for "Already in library:", then Crimson Text italic 13px for the name. Non-interactive. Padding 10px 14px 8px.
    ⑮ Update existing — Dominant choice (~98% of DM intent). Replaces the library entry's abilities in-place; entry's MRU position refreshed (surfaces at top of picker next time).
    ⑯ Save as new — Appends a new entry despite name collision. Library accepts duplicate names — DM may maintain "Drow Priestess (Boss)" and "Drow Priestess" minion variant intentionally.
    C1 Change 1 — Ability list display — Preview rows: line-height 1.45→1.65, bottom padding 8px→10px, ◆ glyph 10px→11px opacity 0.85→1. Expanded card ability block: line-height 1.55→1.7, each ◆ line wrapped in .ab-line with display:block + padding-left:16px + text-indent:−16px for hanging indent. Result: scannable reference list, not a paragraph.
