Design Notes & Annotations
1 Mode toggle auto-switch: Brief §3 specifies that if entries.length > 0 AND round > 0 with no stored preference, the page auto-opens in Session mode with a 400ms accent-border pulse on the pill. Prototype simulates this via the Control Panel toggle.
2 HP bar thresholds: >50% → success green, 20–50% → amber #c8a840, <20% → danger #c06060. Aragorn at 18/24 = 75% → green. Control panel Ally=Bloodied drops to 18/24 which crosses to amber at <50% threshold with border color shift.
3 Initiative glow (Health Glow toggle): NPC/enemy rows in the initiative strip show no extra chrome at full HP. Below 50% they gain yellow left border + box-shadow: 0 0 6px rgba(200,168,64,0.4). Below 25% they gain red left border + box-shadow: 0 0 8px rgba(192,96,96,0.5). Only visible when the Health Glow control is "On".
4 Desktop left column sticky: The left column uses overflow-y: auto with a fixed 700px shell height. On real implementation, position: sticky; top: 44px on the left column while the right column scrolls freely. This is implied by the design-system two-column convention.
5 Session sub-tabs: Map tab is at 0.4 opacity with cursor: not-allowed when no active map (per brief §7). When DM activates a map, tab brightens with 220ms ease-out opacity transition. Prototype shows the dimmed state.
6 Ability chip toast: Tapping any stat chip fires a mock roll (d20 + modifier), shows a result toast for 1.6s via CSS animation, then vanishes. No JS animation library — pure CSS @keyframes toastIn / toastOut with animation-fill-mode: forwards.
7 Persona tab omission: Per brief §4, Persona tab is unreachable in Session mode by design. The session sub-tab strip reads COMBAT · LOADOUT · MAP · NOTES — no Persona. Roleplay traits live in Profile only.
8 Death saves display-only: Brief §14.3 flags player-controlled pips as v2 scope. Unconscious edge case shows pips passively (1 success, 1 fail filled) with no tap target. "UNCONSCIOUS" replaces HP numerals per brief §7.
9 Concentration banner visibility: Brief §11 specifies a ghost + Concentration button when not concentrating. The Control Panel "Combat: On/Off" toggle shows/hides the banner. When hidden, the ghost button appears as a subtle affordance without chrome.
10 prefers-reduced-motion: All CSS animations and transitions are disabled globally when the OS motion preference is set to reduce. Color states (HP colors, border states, text states) are preserved — only timing/motion is removed.
