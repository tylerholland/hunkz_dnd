Prototype Legend
①
Guide trigger icon — 44×44px touch target via padding. SVG open-book. Color: textMuted default → accent on hover → accentBright when drawer is open. Transition: 140ms linear (brief spec §3a). Toggle behavior: re-tapping closes the drawer.
②
Drawer slide animation — Open: translateX(100%→0), 260ms cubic-bezier(0.2,0.8,0.2,1). Close: translateX(0→100%), 220ms cubic-bezier(0.4,0,0.6,1). Asymmetric: opening announces itself, dismissal gets out of the way (brief §7).
③
Gazetteer in-place expansion — max-height eased from 0 to content height. Expand 220ms ease-out. Collapse 180ms ease-in. Chevron ⌄ rotates 90° over the same duration. State persisted in sessionStorage as dnd_guide_gazetteer_expanded.
④
TOC ↔ Reading cross-fade — TOC fades out 90ms ease-in, then reading fades in 160ms ease-in-out with 60ms delay. Total 250ms. On Back, direction reverses. (Brief §7.)
⑤
Resume shortcut — Only shown when sessionStorage.dnd_guide_section is set. In the prototype this is pre-set to "Furyondy" to demonstrate the populated state. Tapping loads the Furyondy reading view directly.
⑥
Tablet scrim — rgba(0,0,0,0.4) overlay fades in/out with the drawer. On desktop (≥1100px) no scrim is applied — the DM may watch HP values while reading lore. Tap-to-close is tablet/mobile only.
⑦
Realm filter — Client-side substring match on title. Items fade out (120ms) then height-collapse (100ms). "No realms match" message shown when list is empty. Filter clears on drawer close. Does not filter content — TOC-level navigation only.
⑧
prefers-reduced-motion — All transitions and animations set to none. State changes remain instant but visible. Implemented via CSS @media query per design-system convention.
⑨
Desktop: no scrim, no tap-to-close outside drawer — clicking the underlying character sheet while the drawer is open does NOT close the drawer. The two surfaces are intentionally co-resident. Only × or Esc close on desktop.
⑩
Body scroll lock — When the drawer is open, overflow:hidden is applied to the app-shell body region to prevent scroll-chaining. overscroll-behavior:contain on the drawer scroll container prevents touch momentum from escaping.
