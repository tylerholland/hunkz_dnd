Over-limit: diamond, count, and note all turn error red. Toggle was allowed (no hard block). The newly-toggled gem flashed red briefly. DM may have granted an exception.

5 Edit Mode — ItemEditorModal
New fields: Requires Attunement checkbox · Currently Attuned (conditional) · Track Quantity checkbox · Qty number input (conditional)

Conditional field visibility rules:
"Currently Attuned" only shows when "Requires Attunement" is checked.
Qty number input only shows when "Track Quantity" is checked.
Unchecking "Requires Attunement" also implicitly sets attuned=false.
Unchecking "Track Quantity" removes the qty field entirely (null/absent).
These are edit-mode (character-level) actions. Live toggling in view mode uses patchSession.
