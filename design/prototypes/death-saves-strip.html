Legend
1
Strip mounts via max-height 0→40px + opacity 0→1 in 300ms ease-out when HP drops to 0. Unmounts opacity first then max-height in 250ms ease-in (brief §5).
2
Pip fill reuses dmConditionIn: scale 0.7→1 + opacity 0→1, 180ms ease-out. Failure pips add strip dmDeathSaveShake after fill completes (+180ms offset).
3
3rd success → green outer glow pulse (dsResolveGlow, 400ms) then strip unmounts. Card dims to 0.85. No "STABLE" label — dimmed card communicates "down but safe" (brief §3e).
4
3rd failure → dmDeathSaveShake → pip row cross-fades out → tombstone fades in (dsTombstoneIn, 300ms). Card dims to 0.7. Cinzel "FALLEN" because the character's life is now a noun (brief §3d).
5
Chevron ⌃ tap: strip grows 40→89px via shortcut row height transition 220ms ease-out. Chevron rotates 180°. Shortcut content fades in with 100ms delay (brief §5).
6
Damage-at-0 prompt fires as pip row contents are replaced. Auto-resolves to No Fail after 12 seconds (timer bar animates). If shortcuts were open they collapse first (180ms) before prompt appears.
7
NAT 20: atomic action — successes=0, failures=0, HP→1, green glow, strip unmounts. NAT 1: staggered 2 failures (+60ms offset), one combined shake at +180ms. ✦ STABLE: deathSaves={0,0}, HP stays 0, strip collapses.
8
Tapping any frozen pip in FALLEN state un-fills it and transitions back to the active pip row (brief §3d reversibility). Card un-dims.
9
Death save colors are universal — not palette-derived — so they read identically on all character palette themes (ember/ocean/forest/etc). Only the No-Fail pill uses var(--pal-text-muted) as the neutral exit (brief §3c).
10
NAT20/✦STABLE pills are left-grouped (roll outcomes); ✦STABLE is right-aligned (external intervention). The semantic asymmetry is intentional per brief §3b.
